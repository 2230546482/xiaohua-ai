#打开12大流派选择（支持队列防挤掉 + 音效提示 + 防误触静默提醒，AI走智能流派决策）
flower_ai_open_starter_selection = {
	if = {
		limit = { is_ai = no }
		scoped_sound_effect = "alert_pick_new_idea_sound"
		if = {
			limit = { check_variable = { flower_draft_gui_mode > 0 } }
			add_to_variable = { flower_queue_starter = 1 }
			flower_ai_recalc_pending_drafts = yes
			if = {
				limit = { has_country_flag = flower_draft_manual_open }
				clr_country_flag = flower_anomaly_panel_open
				clr_country_flag = flower_history_gui_open
				set_country_flag = flower_roguelike_gui_open
				clr_country_flag = flower_draft_manual_open
			}
		}
		else = {
			set_variable = { flower_draft_gui_mode = 1 }
			set_variable = { flower_draft_starter_page = 1 }
			flower_ai_recalc_pending_drafts = yes
			if = {
				limit = {
					OR = {
						has_country_flag = flower_draft_manual_open
						NOT = { has_country_flag = flower_draft_silent_popup }
					}
				}
				clr_country_flag = flower_anomaly_panel_open
				clr_country_flag = flower_history_gui_open
				set_country_flag = flower_roguelike_gui_open
			}
			clr_country_flag = flower_draft_manual_open
		}
	}
	else = {
		flower_ai_smart_pick_archetype = yes
	}
}
